    Per maand: finance tegenover het datawarehouse

    Het datawarehouse, in je browser

    SQLite via sql.js (WebAssembly): dimensies, feiten, KPI-views en datakwaliteitstabellen. Alleen lezen; elke query draait op je eigen toestel. Dezelfde views bestaan in T-SQL en worden in CI op SQL Server 2022 vergeleken.

    Database wordt geladen bij het openen van dit tabblad (± 6,5 MB).
